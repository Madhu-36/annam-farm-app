# Contributing to Annam Farm Intelligence

Thank you for your interest in contributing to **Annam Farm Intelligence**! 🌾

We welcome contributions from developers, agronomists, data scientists, and anyone passionate about using AI to improve the lives of Indian farmers. Please take a moment to review these guidelines before submitting your first contribution.

---

## 🤝 Code of Conduct

By participating in this project, you agree to maintain a respectful and inclusive environment. We follow the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

---

## 🛠️ How to Contribute

### 1. Fork the Repository
Click the **Fork** button at the top right of the [repository page](https://github.com/Madhu-36/annam-farm-app) to create your own copy.

### 2. Clone Your Fork
```bash
git clone https://github.com/YOUR-USERNAME/annam-farm-app.git
cd annam-farm-app
```

### 3. Create a Branch
Always create a new branch for your changes. Use a descriptive name:
```bash
# For new features
git checkout -b feature/your-feature-name

# For bug fixes
git checkout -b fix/bug-description

# For documentation
git checkout -b docs/what-you-updated
```

### 4. Make Your Changes
- Keep changes focused and atomic (one feature/fix per PR)
- Follow the existing code style (Vanilla JS, no frameworks)
- Test your changes in the browser before committing
- Ensure the app still works fully offline

### 5. Commit Your Changes
Write clear, meaningful commit messages:
```bash
git add .
git commit -m "feat: add soil pH input to harvest form"
```

**Commit message prefixes:**
| Prefix | Use For |
|---|---|
| `feat:` | New features |
| `fix:` | Bug fixes |
| `docs:` | Documentation updates |
| `style:` | CSS/UI changes |
| `refactor:` | Code refactoring |
| `data:` | Dataset updates |
| `chore:` | Build/config updates |

### 6. Push and Open a Pull Request
```bash
git push origin feature/your-feature-name
```
Then open a Pull Request on GitHub with a clear description of what you changed and why.

## 🐛 Reporting Bugs

Found a bug? Please [open an issue](https://github.com/Madhu-36/annam-farm-app/issues/new) with the following information:
- **Description** of the bug
- **Steps to reproduce** the issue
- **Expected behavior** vs actual behavior
- **Browser and OS** you are using
- **Screenshots** if applicable

---

## 💡 Suggesting Features

Have an idea? We'd love to hear it! [Open a feature request](https://github.com/Madhu-36/annam-farm-app/issues/new) and describe:
- The problem you are trying to solve
- Your proposed solution
- How it benefits farmers

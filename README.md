# Annam Farm Intelligence 🌾🤖

An Enterprise-grade Agricultural Data Science & AI application designed to empower smallholder farmers with actionable intelligence.

## 📖 Overview
Built as a progressive offline-first web application, Annam Farm Intelligence helps farmers log harvest data, track yield trends, and utilize artificial intelligence to predict future crop performance and identify plant diseases. 

## ✨ Key Features
*   **AI Yield Predictor & Economics:** Uses advanced data forecasting to predict crop yields based on historical farm data, and estimates financial revenue using live APMC Mandi market rates.
*   **Computer Vision Leaf Scanner:** Upload photos of diseased crops to receive instant AI pathology diagnostics, complete with chemical and organic treatment plans.
*   **Offline-First Architecture:** Because rural farms often lack internet access, the app is built as a PWA (Progressive Web App). It runs locally in the browser utilizing `LocalStorage` memory.
*   **Voice Dictation:** Integrated Web Speech API allows farmers to log data by speaking in regional accents, bypassing complex typing.
*   **National Agronomy Database:** A built-in guide detailing soil, rainfall, and climate requirements for India's major crops.
*   **Enterprise Dashboard:** Secure authentication, an administrative portal, and personalized tracking of historical harvest logs.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, Vanilla CSS (Custom Corporate Theme), JavaScript (ES6+)
*   **Data Visualization:** Chart.js
*   **Backend Support:** Python, FastAPI, Scikit-Learn (K-Nearest Neighbors)
*   **Storage:** Local Browser Storage & JSON
*   **PWA:** Service Workers and Web Manifest for mobile installation.

## 🚀 Installation & Usage
Because the application includes a robust offline fallback mode, no server installation is required to run the frontend!

1. Clone the repository: 
   ```bash
   git clone https://github.com/Madhu-36/annam-farm-app.git
   ```
2. Navigate to the `frontend` folder.
3. Open `login.html` in any modern web browser.
